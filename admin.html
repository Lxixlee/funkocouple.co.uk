FUNKO COUPLE

Store Admin

Admin login

Enter your admin password to manage the Funko Couple website. GitHub access is handled securely by the site's admin service — you do not need a GitHub token.

Site Logo

Change the logo used across the website. Upload a new logo and then click SAVE LOGO.

Shop Products

Add, edit and remove the products that appear in the shop. You can upload a product image, set the price and stock, choose one or more categories, and control the product details.

Category Images

Upload the main image used on each homepage category card. Use a clear, high-resolution image — around 1200 × 800px works well. The image is stored separately, so replacing it will not make it blurry.

Category Banners

Change the image, heading, supporting text and button text for every category slide.
